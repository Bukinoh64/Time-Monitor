# Монитор времени

Небольшое Windows Forms-приложение для учёта времени работы выбранных программ.

## Требования

- Windows
- .NET 8 SDK или новее

## Запуск

Дважды щёлкните `run.bat` в папке проекта. Скрипт запускает приложение командой `dotnet run`.

Или откройте `WinFormsApp5.csproj` в Visual Studio и запустите проект.

## Использование

1. Нажмите **«Добавить в список»** и выберите `.exe` нужной программы.
2. Нажмите **«Начать»**, чтобы начать отслеживание, или **«Остановить»**, чтобы приостановить его.
3. Просматривайте общее время, активные приложения, график и таблицу статистики. Доступны периоды: сегодня, 7 дней, 30 дней и год.

Общее время считает период, когда запущено хотя бы одно отслеживаемое приложение; параллельно запущенные приложения не суммируются. Время каждого приложения учитывается отдельно.

## Файлы данных

Файлы создаются в текущей рабочей папке приложения:

- `tracker_data.txt` — накопленное время для каждого приложения.
- `usage_history.txt` — история использования для графика и отчётов.
- `Stats.txt` — текстовый отчёт, обновляемый при остановке или закрытии приложения.
